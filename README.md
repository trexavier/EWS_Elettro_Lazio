# EWS_Elettro_Lazio

Software di previsione, simulazione e analisi delLa vulnerabilità geospaziale, con applicazione
al monitoraggio dell'infrastruttura di distribuzione elettrica della regione Lazio esposta agli
eventi climatici avversi (ondate di calore, elevate temperature, precipitazioni, ghiaccio, vento).

I componenti elettrici analizzati sono: linea elettrica interrata, linea elettrica sospesa, tralicci,
pali di servizio, cabine elettriche, trasformatori di distribuzione e trasformatori di potenza.

L'applicazione consente il download di dati climatici open ed elabora mappe di vulnerabilità con
scala regionale (risoluz. 0.25 e 0.1 gradi con previsione 7 gg) e provinciale 
(risoluzione 0.02 gradi con previsione 3 gg).

Le mappe generate dall'applicazione evidenziano sulla cartogrfia di base il layer di fragilità
degli specifici elementi elettrici in esame, ovvero poligoni di superficie colorati in base a una scala
cromatica graduata di riferimento, in relazione alle probabilità di guasto del componente esposto all'intensità
dell'evento avverso. Inoltre, l'utente può selezionare ulteriori layer da sovrapporre, tra cui:
rete elettrica regionale o provinciale, mappe del rischio alluvione, ubicazione degli elementi
dell'infrastruttura. In tutti i casi, gli scenari generati prevedono la visualizzazione dei
confini amministrativi (intera regione, province, comuni).

Un semplice manuale utente è stato inserito nella cartella conf.
